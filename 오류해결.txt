지원사업 공고첨부 받기 — 오류 나면 여기 보세요
=====================================

■ 한글이 깨져 보일 때 (꿝ㄹ가ㅜ후 같은 글자)
  → 예전 ZIP 입니다. GitHub에서 ZIP을 다시 받으세요.
  → Code → Download ZIP (main 또는 이 저장소 최신)
  → 풀린 폴더에서 처음설치_한번만.cmd 다시 실행

■ "scripts 폴더를 찾을 수 없습니다"
  → ZIP 풀린 폴더 안에서 실행하세요.
  → cmd 파일만 바탕화면으로 복사하면 안 됩니다.

■ "Python 이 없습니다" / Python not found
  → https://www.python.org/downloads/ 설치
  → 설치 시 [Add python.exe to PATH] 체크 필수
  → 설치 후 처음설치_한번만.cmd 다시 실행

■ "pip 설치 실패" / 패키지 설치 실패
  → 인터넷 연결 확인
  → 회사 PC면 방화벽 때문에 막힐 수 있음
  → Python 재설치 시 pip 포함 옵션 체크

■ 올바른 실행 순서 (GitHub 원본 ZIP)
  1. GitHub → Code → Download ZIP
  2. 압축 해제 후 폴더 열기
  3. 처음설치_한번만.cmd (1회)
  4. 지원사업 공고첨부_받기.cmd (평소)

■ 그래도 안 되면
  검은 창에 나온 글씨 전체를 캡처해서 보내 주세요.
