지원사업 공고첨부 받기 — EXE (Python 불필요)
==========================================

■ 받는 사람
1. 지원사업_공고첨부_받기.exe 를 바탕화면 등에 저장
2. 더블클릭
3. 공고 상세 페이지 주소 붙여넣기 → Enter
4. 첨부는 바탕화면「지원사업_공고첨부」폴더에 저장됨

■ 어디서 받나
- GitHub Actions 아티팩트: workflow "Build Attach Downloader EXE"
- 또는 dist/지원사업_공고첨부_받기.exe (빌드 후 커밋/배포된 경우)

■ 참고
