지원사업 공고첨부 받기 — EXE (Python 불필요)
==========================================

■ 받는 사람 (제일 간단)
1. 지원사업_공고첨부_받기.exe 저장 (또는 _exe.zip 받아서 풀기)
2. 더블클릭
3. 공고 상세 페이지 주소 붙여넣기 → Enter
4. 첨부는 바탕화면「지원사업_공고첨부」폴더에 저장
