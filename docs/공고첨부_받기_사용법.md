# 공고 첨부파일 받기 (비개발자용)

공고 상세 페이지 URL만 붙여넣으면 첨부파일(hwp/pdf 등)을 받아 주는 프로그램입니다.
메일 발송·API 키는 필요 없습니다.

## 남에게 줄 때 (주는 사람)

1. 이 저장소 폴더에서 `배포용_압축하기.cmd` 더블클릭
2. 바탕화면에 생긴 `지원사업_공고첨부_받기_설치.zip` 을 카톡/메일로 전달
3. `.env` / 비밀번호 / API 키는 절대 포함하지 마세요 (`배포용_압축하기.cmd`가 제외합니다)

## 받은 사람 (처음 1회)

1. ZIP 압축 해제
2. `처음설치_한번만.cmd` 더블클릭 → 끝날 때까지 대기 (1~3분)
3. Python이 없으면 설치 안내가 뜹니다. **Add python.exe to PATH** 체크 필수

## 평소 사용

1. `지원사업 공고첨부_받기.cmd` 더블클릭
2. 공고 URL 붙여넣기 → Enter
3. 파일은 바탕화면 `지원사업_공고첨부` 폴더에 저장됩니다
4. 종료: 빈 줄에서 Enter

## 구성 파일

| 파일 | 역할 |
|------|------|
| `처음설치_한번만.cmd` | Python·패키지·저장폴더 1회 설치 |
| `지원사업 공고첨부_받기.cmd` | 평소 실행 (더블클릭) |
| `배포용_압축하기.cmd` | 배포 ZIP 생성 |
| `사용방법_공고첨부.txt` | 메모장용 짧은 안내 |
| `scripts/setup_attach_downloader.py` | 실제 설치 로직 |
| `scripts/requirements-attach.txt` | 최소 의존성 |
| `scripts/fetch_notice_attachments.py` | 첨부 다운로드 본체 |
