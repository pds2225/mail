# streamlit_app.py — 관리 대시보드

> **한 줄 요약:** 웹 브라우저에서 프로그램 설정을 관리하는 화면입니다.

---

## 이 파일이 하는 일 (비유)

**스마트폰의 "설정" 앱**과 비슷합니다. 코드를 몰라도:
- 어떤 사이트에서 수집할지 설정하고
- 어떤 조건으로 필터링할지 바꾸고
- 수신자 이메일을 관리하고
- 현재 수집 상태를 한눈에 볼 수 있습니다.

---

## 실행 방법

```powershell
python -m streamlit run streamlit_app.py
```

브라우저에서 `http://localhost:8501`로 열립니다.

---

## 주요 기능 (탭별)

### 📋 소스 관리
- `sites.json`의 수집 소스를 테이블로 보여주고
- 활성/비활성 토글
- 사이트 타입·URL·수집 주기 설정

### 👥 그룹 관리
- `groups.json`의 수신자 그룹을 관리
- 각 그룹의 키워드·지역·지원유형 조건 설정
- 수신자 이메일 목록 관리

### ⚙️ 전역 설정
- `settings.json`의 전역 옵션 (수집 주기, 필터링 설정 등)

### 📊 수집 현황
- 최근 수집 결과 요약
- 사이트별 수집 건수·실패 건수
- 커버리지 점검 결과

---

## 기술적 특징

- **Streamlit** 프레임워크 사용 (Python으로 웹 UI 만드는 도구)
- `private_config`로 수신자 이메일 등 민감 정보를 별도 관리
- `state_store`로 설정 변경 시 원자적 쓰기 (중간에 꺼져도 안 깨짐)

---

## 주의사항

- **실제 메일 발송은 이 화면에서 하지 않습니다** — 설정만 변경합니다
- `sites.json`·`groups.json`·`settings.json`을 직접 편집하는 것과 같습니다
- 변경은 즉시 반영되나, 자동 발송 스케줄은 별도로 동작합니다
