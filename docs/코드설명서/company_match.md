# company_match.py — 기업별 정밀 매칭

> **한 줄 요약:** "이 공고가 우리 회사에 정말 맞나"를 기업 프로필 기준으로 점수를 매겨 판단합니다.

---

## 이 모듈이 하는 일 (비유)

**취업 포털의 "나에게 맞는 공고 추천"**과 비슷합니다.

일반 필터링(그룹 단위)은 "인천 기업이면 OK"처럼 **넓게** 봅니다.
company_match는 **개별 기업의 특성**까지 봅니다:
- 우리 회사는 "인천 남동구"에 있고
- "제조업"이고
- "공장이 있고"
- "수출을 합니다"
→ 이 조건에 딱 맞는 공고만 골라줍니다.

---

## 핵심 함수

| 함수 | 하는 일 |
|---|---|
| `load_companies()` | `companies.json`에서 기업 프로필을 읽어옴 |
| `compute_match_score()` | **핵심**: 공고와 기업 프로필을 비교해 점수(0~100)를 매김 |
| `match_for_company()` | 한 기업에 모든 공고를 매칭해 점수순으로 정렬 |
| `refine_included_by_company()` | monitor.py의 1차 필터 결과를 기업 점수로 다시 걸러냄 |

---

## 점수 매기는 방법

각 항목에 점수를 더하거나 뺍니다:

| 항목 | 점수 | 설명 |
|---|---|---|
| 산업 키워드 히트 | +12 each | "제조업" 관련 공고 |
| 관심 키워드 히트 | +8 each | "수출" 관련 공고 |
| 지역 일치 (구) | +30 | 우리 구(남동구)에 한정된 공고 |
| 지역 일치 (시) | +22 | 우리 시(인천)에 한정된 공고 |
| 전국 대상 | +14 | 전국任何一个都可以申请 |
| 공장 보유 보너스 | +10 | 공장이 있는 우리 + 공장 조건 공고 |
| 수출 보너스 | +10 | 수출 지향 우리 + 수출 공고 |
| 지원유형 일치 | +8 | 우리가 선호하는 지원유형 |
| **제외 키워드** | **-50 each** | 우리와 안 맞는 키워드 |
| **지역 불일치** | **-40** | 명백히 다른 지역 한정 |

**기준점: 60점 이상이면 "보내도 됩니다"**

## companies.json 형식

```json
{
  "id": "company1",
  "name": "우리 회사",
  "region": {"city": "인천", "district": "남동구"},
  "industry_keywords": ["제조업", "스마트팩토리", "자동화"],
  "interest_keywords": ["수출", "해외", "박람회"],
  "exclude_keywords": ["설명회", "교육"],
  "has_factory": true,
  "export_focus": true,
  "support_type_prefs": ["지원금/바우처", "수출바우처"]
}
```

## monitor.py와 어떻게 연결되나

monitor.py의 `evaluate_notice()`가 1차 필터를 통과한 공고에 대해,
company_match가 **2차 정밀 필터**를 수행합니다:

```
[전체 공고] → evaluate_notice() 1차 → [적격 공고] → company_match() 2차 → [최종 발송]
```

---

## 안전 규칙

- 이 모듈은 **메일을 보내지 않습니다** — 점수만 매깁니다
- 수신자 이메일은 마스킹해서 로그에 남깁니다
- `companies.json`에 민감한 정보가 없도록 주의합니다
