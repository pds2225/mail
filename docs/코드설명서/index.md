## 이 프로그램은 뭘 하나요?

**"정부지원사업 공고를 인터넷에서 자동으로 모아, 우리 회사에 맞는 것만 골라 메일로 보내주는 도우미"**입니다.

하루에 수십 건의 지원사업 공고가 정부 사이트에 올라옵니다. 사람이 일일이 확인하기엔 너무 많죠. 이 프로그램은:

1. **여러 사이트에서 공고를 수집**합니다 (기업마당, K-Startup, NIPA 등 20개)
2. **우리 회사 조건에 맞는 것만** 골라냅니다 (지역, 지원유형, 키워드 등)
3. **메일로 보내줍니다** (Claude AI가 요약까지 해줌)

## 설정 파일이 뭘 하나요?

| 파일 | 내용 | 비유 |
|---|---|---|
| `sites.json` | 어떤 사이트에서 수집할지 목록 | **수집 대장** |
| `groups.json` | 어떤 조건(지역·키워드)으로 필터링할지 | **선발 기준** |
| `settings.json` | 메일 발송 관련 전역 설정 | **운영 매뉴얼** |
| `companies.json` | 우리 회사 정보 (지역·산업·관심사) | **회사 프로필** |
| `seen_ids.json` | 이미 보낸 공고 목록 (중복 방지) | **발송 이력** |
