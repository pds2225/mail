지원사업 공고첨부 받기 — 사용 방법 (비개발자용)
================================================

■ 받은 사람이 할 일 (처음 1회)
1. ZIP 파일을 원하는 위치에 압축 해제합니다.
2. 풀린 폴더에서 「처음설치_한번만.cmd」 를 더블클릭합니다.
3. 검은 창이 열리면 끝날 때까지 기다립니다. (인터넷 필요, 1~3분)
4. Python 이 없다면 설치 안내가 나옵니다.
   - 설치 화면에서 반드시 [Add python.exe to PATH] 에 체크하세요.
   - 설치 후 PC를 재시작하거나, 「처음설치_한번만.cmd」를 다시 실행하세요.

■ 평소 사용
1. 「지원사업 공고첨부_받기.cmd」 를 더블클릭합니다.
2. 공고 상세 페이지 주소(URL)를 붙여넣고 Enter 를 누릅니다.
3. 첨부가 바탕화면의 「지원사업_공고첨부」 폴더에 저장됩니다.
4. 끝내려면 빈 줄에서 Enter 를 누릅니다.

■ 주는 사람이 할 일
1. 이 프로그램이 있는 폴더에서 「배포용_압축하기.cmd」 를 더블클릭합니다.
2. 바탕화면에 생긴 ZIP 을 카톡/메일로 보냅니다.
3. .env, 비밀번호, API 키는 절대 같이 보내지 마세요.

■ 문제 생길 때
- 「처음설치_한번만.cmd」 를 다시 실행해 보세요.
- 회사 PC 는 방화벽 때문에 설치가 막힐 수 있습니다. 인터넷이 되는 PC에서 설치하세요.
- 창이 바로 닫히면, 같은 폴더에서 마우스 오른쪽 → 편집으로 열어
  맨 아래 "pause" 가 있는지 확인하거나 담당자에게 문의하세요.
